## 📌 Project Overview

An end-to-end Data Analytics and Machine Learning project focused on pharmaceutical supply chain optimization, packaging yield prediction, material planning, and distribution performance.

The project combines statistical analysis, predictive modelling, and interactive dashboards to support data-driven operational decision-making.

## 🤖 Predictive Yield Analytics

A Random Forest Regression model was developed to predict pharmaceutical packaging yield.

### Model Configuration

- Algorithm: Random Forest Regressor
- Number of Estimators: 100
- Training-Testing Split: 80:20
- Target Variable: Packaging Yield Percentage

### Performance Evaluation

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Percentage Error (MAPE)
- R-squared Score (R²)

Model evaluation results are available in `model_performance.csv`.
